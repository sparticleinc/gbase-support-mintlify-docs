GBase Knowledge は、会議の音声を自動で文字起こし・要約し、その内容から提案資料（スライド）を作成し、蓄積された社内情報を横断的に検索・活用できる AI ワークスペースです。

本マニュアルでは、実際の業務の流れに沿って、以下の順に操作手順をご説明します。

### 動作環境

* 対応ブラウザ：Google Chrome、Microsoft Edge、Safari の最新版を推奨します。
* アカウント：管理者から発行されたメールアドレスとパスワードをご用意ください。

### 1. ログイン

1. ブラウザで [https://hub.gbase.ai/auth/login](https://hub.gbase.ai/auth/login) にアクセスします。
2. 「メールアドレス」欄に、発行されたメールアドレスを入力します。
3. 「パスワード」欄にパスワードを入力します。
4. 「サインイン」ボタンをクリックします。

<Frame caption="ログイン画面">
  <img src="/images/knowledge/01-login.png" alt="ログイン画面" />
</Frame>

ログインに成功すると、ホーム画面が表示されます。

<Note>
パスワードをお忘れの場合は、ログイン画面の「パスワードをお忘れですか？」リンクから再設定できます。
</Note>

### 2. ホーム画面の構成

ホーム画面は、GBase Knowledge のすべての機能への入口です。

<Frame caption="ホーム画面">
  <img src="/images/knowledge/02-home.png" alt="ホーム画面" />
</Frame>

| 画面の場所 | 名称 | 説明 |
| --- | --- | --- |
| 左サイドバー | ホーム | この画面（ホーム）に戻ります |
| 左サイドバー | プロジェクト | 情報を蓄積・共有するプロジェクトの一覧を表示します |
| 左サイドバー | 履歴 | 過去の質問・会議・スライドの履歴を表示します |
| 左サイドバー | スキル | ワークショップ機能（拡張スキル）を表示します |
| 左サイドバー | GBase をダウンロード | デスクトップアプリ（GBase アプリ）をダウンロードします。会議の録音に利用でき、録音した音声は自動でプロジェクトにアップロードされ、文字起こし・要約まで自動で行われます |
| 左サイドバー | 設定 | 言語設定・アカウント情報・外部サービス連携を行います |
| 左サイドバー | 管理画面 | 管理者向けの管理コンソールを開きます |
| 中央 | 入力ボックス | 質問やタスクを入力します（@でファイル・プロジェクトを参照できます） |
| 中央下 | 機能ボタン | 「エージェント」「AIスライド」「AI会議ノート」「音声をアップロード」の各機能を起動します |
| 右上 | クレジット | AI 機能の利用可能残量を表示します |

### 3. 表示言語の切り替え

画面の表示言語は、ユーザーごとに変更できます。

1. 左サイドバーの「設定」をクリックします。
2. 「言語」の選択ボタンをクリックします。
3. 「日本語」「English (US)」「中文 (简体)」「中文 (繁體)」「한국어」から選択します。
