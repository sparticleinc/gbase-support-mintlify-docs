プロジェクトは、会議記録・ファイル・ノートをテーマごとに蓄積する「知識の入れ物」です。蓄積された情報は、[エージェント](/knowledge/agent-search)の検索・質問の対象になります。

### 1. プロジェクトの一覧と作成

左サイドバーの「プロジェクト」をクリックすると、プロジェクト一覧が表示されます。

<Frame caption="プロジェクト一覧画面">
  <img src="/images/knowledge/10-project-list.png" alt="プロジェクト一覧画面" />
</Frame>

* 「全てのプロジェクト」「お気に入り」「所有」「管理」「閲覧」のタブで絞り込みできます。
* 「新しいプロジェクト」をクリックすると、新規プロジェクトを作成できます。

### 2. プロジェクト詳細画面

プロジェクトカードをクリックすると、詳細画面が表示されます。

<Frame caption="プロジェクト詳細画面">
  <img src="/images/knowledge/11-project-detail.png" alt="プロジェクト詳細画面" />
</Frame>

| 画面の場所 | 機能 |
| --- | --- |
| 上部 | 「音声をアップロード」：このプロジェクトに直接会議音声を追加します |
| 上部 | 「共有」：プロジェクトをメンバーに共有します（プライベート／共有の切替） |
| 中央タブ | 「ノート」「会議ノート」：蓄積されたノート・会議記録の一覧を表示します |
| 中央下 | 入力ボックス：このプロジェクトの内容だけを対象に質問できます |
| 右側 | 「ファイル追加」「リンク追加」：資料・URL をプロジェクトに追加します |
| 右側 | コネクター：SharePoint Online・Box・Google Drive と接続し、既存の社内資料を取り込めます |

<Note>
日々の会議をプロジェクトに蓄積していくだけで、チームの知識ベースが自動で育っていきます。新しいメンバーへの引き継ぎや、過去の経緯の確認が格段に楽になります。
</Note>

### 3. ソースを追加する（ファイル・リンク・コネクター）

詳細画面の右側にある「ソース」パネルから、会議記録以外の資料もプロジェクトに学習させることができます。学習されたソースは、[エージェント](/knowledge/agent-search)の検索・質問の対象になります。

<Frame caption="「ソース」パネル：ファイル追加・リンク追加・コネクター">
  <img src="/images/knowledge/11b-project-sources.png" alt="ソースパネル" />
</Frame>

#### ファイルを追加する

1. 「ファイル追加」をクリックします。
2. ファイル選択ダイアログで、追加したい資料を選びます（PDF・Word・Excel・PowerPoint・テキストなど）。複数選択もできます。
3. アップロードすると、自動で内容の解析（学習）が始まります。「学習中」の表示が完了に変わると、エージェントの検索対象になります。

<Tip>
契約書・提案書・製品資料など、繰り返し参照する資料を入れておくと、エージェントへの質問だけで内容を引き出せます。
</Tip>

#### リンクを追加する

1. 「リンク追加」をクリックします。
2. 取り込みたい Web ページの URL を入力します。
3. システムがページの内容を取得し、ファイルと同じように学習します。

#### 外部コネクターと連携する（SharePoint・Box・Google Drive）

社内で既に利用しているストレージサービスと接続し、既存の資料をプロジェクトに取り込めます。

1. 「コネクター」の一覧から、連携したいサービス（SharePoint Online・Box・Google Drive）の「接続」をクリックします。
2. 各サービスのログイン・認可画面が開きます。画面の案内に従ってアクセスを許可します。
3. 接続が完了すると、状態の表示が「未接続」から「接続済み」に変わります。
4. 接続済みのサービスでは「構成」をクリックし、取り込む対象（フォルダー・ファイル）を選びます。
5. 選んだ資料が学習され、エージェントの検索対象になります。

<Warning>
コネクター連携には、対象サービス側のアクセス権限が必要です。管理者による事前設定が必要な場合は、貴社の管理者にご確認ください。学習されるのは、アクセスを許可した範囲の資料のみです。
</Warning>
